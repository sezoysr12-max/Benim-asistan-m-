# Benim Asistanım

Sahibinden ilanlarını hazırlamak için geliştirilen özel asistanın başlangıç projesi.

## Güvenlik
OpenAI API anahtarı Android uygulamasına veya GitHub deposuna yazılmaz.
Anahtar yalnızca sunucunun ortam değişkeninde tutulur: `OPENAI_API_KEY`

## Yapı
- `app/`: Android uygulaması
- `server/`: OpenAI bağlantısını yapan sunucu

Bu sürüm bağlantı iskeletidir. Fotoğraf analizi, fiyat araştırması, ilan metni ve Sahibinden iş akışı sonraki aşamalarda eklenecek.
